## 1. Deploy Steps

Run in sequence during deploy window. **Stop and assess if any step fails.**

### 1.1 Connect to Production

```bash
# SSH to production server (get host from 1Password or team runbook)
ssh user@production-server
cd /path/to/project
```

### 1.2 Stack-Specific Deploy

```bash
# Pull latest main
git pull origin main

{{#if stack_is_laravel}}
# PHP / Laravel
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan optimize
php artisan queue:restart
php artisan horizon:terminate 2>/dev/null || true
{{/if}}

{{#if stack_is_node}}
# Node.js
npm ci
npm run build
pm2 restart all 2>/dev/null || systemctl restart node-app 2>/dev/null || true
{{/if}}

{{#if stack_is_python}}
# Python
pip install -r requirements.txt
python manage.py migrate
systemctl restart gunicorn 2>/dev/null || true
{{/if}}

{{#if stack_is_go}}
# Go
go build -o ./bin/app ./cmd/...
systemctl restart app 2>/dev/null || true
{{/if}}
```

### 1.3 Verify Deploy

```bash
# Quick smoke test — check app responds
curl -sf https://your-app.com/health | jq .

# Check for migration errors in logs
tail -20 storage/logs/laravel.log   # Laravel
# or
journalctl -u your-app --since "5 minutes ago"   # systemd
```

```bash

git revert --no-commit <LAST_TAG>..HEAD
git commit -m "🔀 merge: revert aggregate deploy <DATE>"
```
